5. EXACT SMALL-PREFILL PATH
Source establishes:
const bool stream_all = m.ring > STAGE && T >= stream_all_min() && m.src != nullptr;
At T512 stream_all=false.
Therefore 512 uses small path, not stream_all scheduler. STRATA_PF_PEER_STREAM inactive at 512.

Small path has STAGE=8. stage_one for every routed nonresident expert issues a fresh H2D into recycled stage_dev slot. Execution waits copied event and compute() uses stage_dev. Persistent residents use cache->device_slot and compute(...,-1).
Thus same (layer,expert) routed in successive 512 chunks is retransferred unless persistently resident.

9. CURRENT PATCH — TWO-GENERATION DESIGN
We then corrected architecture:
- total retention remains 384MiB/card; cannot allocate 384+384 because headroom insufficient.
- split arena into TWO ~192MiB banks.
- one bank frozen as lookup generation during current invocation.
- other bank collects current invocation tail via circular replacement.
- on next invocation swap roles.
- misses remain on normal STAGE=8 H2D path.
- after normal H2D into stage_dev, copy expert stage_dev -> write-bank via D2D, so no additional PCIe H2D.
- retention hit waits retain_copied and computes from retained stable pointer; records retain_used.
- write-bank overwrite waits retain_used.
- feature gated STRATA_SMALL_RETAIN_MIB; devices1/2 only; GPU0 unchanged.

12. INTERPRETATION / DIRECTION
The strongest proven fact is not merely that PCIe is slow; it is that Strata repeatedly retransfers the same experts across 512 microbatches while the x1 links are already saturated at their physical throughput. Adjacent reuse is ~70–76% on the constrained GPUs. This is structurally analogous to the opportunity exploited by llama TurboPrefill: preserve a larger logical horizon while executing in smaller bounded microbatches. The current retention work is a minimal experiment toward that behavior without rewriting Strata's scheduler.

Please continue from the current two-generation build, not from the failed rolling-cache policy, and preserve all measurements/artifacts.
