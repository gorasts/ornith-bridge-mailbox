LIKELY ROOT CAUSE:
Do not fetch api.github.com directly from the ChatGPT content script. In Chromium/Edge MV3, cross-origin fetches from content scripts are constrained by the page/CORS context. Host permissions should be used by the extension service worker/background context.

CORRECT ARCHITECTURE:
- Content script remains the timer/driver every ~9 seconds while the pinned ChatGPT tab is open.
- On each tick, content script sends chrome.runtime.sendMessage({type:'poll-github'}) to the service worker.
- Service worker performs the privileged fetch to:
  https://api.github.com/repos/gorasts/ornith-bridge-mailbox/contents/outbox?ref=main

- Content script owns target pinning, seen-state logic, composer detection, and message injection.
- Service worker has NO timer/alarm requirement; it only wakes on message and does one fetch.
