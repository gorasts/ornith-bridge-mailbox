4. BUILD THE CORRECT RESOURCE/DEPENDENCY MODEL FIRST

For each UB u, stage s, enumerate resources: input activation, output activation, intermediate snapshot, Q8KV/attention state, expert weight slices/copies, staging host allocation, Vulkan VkBuffer+offset, graph metadata, CPU offload temporary and owner GPU scratch. Build a producer-consumer DAG:
- data producer on GPU A compute must COMPLETE and its writes be visible before D2H reads;
- D2H must COMPLETE and mapped memory be invalidated if noncoherent before CPU reads/reuses it;
- source staging bytes remain immutable until the H2D GPU transfer actually finishes reading them;
- H2D complete+visible to shader before consumer GPU B reads destination;
- no destination overwrite until previous consumers finish; no staging slot reuse until its reader is complete;
- within attention layer, later UB sees required prior KV state; model causal semantics maintained;
- blk5/8/20/35 CPU expert detours must be grouped as atomic dependencies with the owning layer, including GPU->CPU routing, expert computation, CPU->GPU result, gated/up/down/swiglu, temporary scratch.
Track producer_done / copy_done / consumer_done separately. An event recorded after enqueue is NOT a completed transfer. A valid pinned pointer is NOT a completed transfer. Host-coherent allocation is NOT an execution dependency. Barriers on one queue do not magically synchronize different queues/devices.

Implement or audit a bounded ring per (GPU, UB slot, resource kind), 2-3 slots initially within measured headroom (GPU1 ~857 MiB remaining and GPU2 ~1131 MiB in Grok's report; do NOT assume unbounded buffering). Each slot has explicit FREE -> D2H_INFLIGHT -> HOST_READY -> H2D_INFLIGHT -> GPU_READY -> COMPUTE_INFLIGHT -> CONSUMED -> FREE lifecycle, with owned fence/timeline value/byte range and gen counter. Avoid copying full graph/state for each slot where a small activation suffices. CPU-side memcpy into a per-GPU pinned source buffer should occur only while that slot is free, and its lifetime must extend past the device read. For coherent host buffers obey ordering; for noncoherent host-visible allocations flush/invalidate aligned to nonCoherentAtomSize. For separate transfer/compute queues insert correct transfer write -> compute shader read availability/visibility and queue-family ownership if needed; queue semaphores/timeline must order cross-queue submits. For distinct VkDevices, do not assume native same-device semaphore works across cards: use host side completion/event bridging or explicitly verified external semaphore capabilities.

DO NOT restore a single global vkQueueWaitIdle/ggml_vk_synchronize as a 'correctness fix'. Synchronize only the specific dependency, while unrelated GPU work proceeds. But equally DO NOT omit a required wait from an upload just because copying into pinned memory seems safe.
