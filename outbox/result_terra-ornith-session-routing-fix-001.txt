ROUTING_DESIGN:
HARNESS/bridge-session.json is the single explicit local target binding. The worker reads and validates it for each job, compares it with helper /health, passes the same UUID to /follow, and sends session/prompt only to that UUID. The helper reads the binding for /follow and permits session/prompt or session/selectModel only when the requested UUID equals the bound UUID; its listener remains 127.0.0.1:3099. No arbitrary-session mutation endpoint was added. HarnessBridge.mjs now provides local `bind <existing-session-uuid>`, which verifies the exact UUID through native session/list and atomically writes the binding; a rebind requires no helper/worker restart. Existing mailbox dedupe, result publication, and wake code remain unchanged.
