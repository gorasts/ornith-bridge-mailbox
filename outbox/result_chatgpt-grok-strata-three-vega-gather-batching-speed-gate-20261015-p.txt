give_back() on the Stage K issuer (STRATA_PREFILL_ISSUER=0) calls issue_until(upto + ring) (2162-2164). issue_until() waits on used[used_of[slot]] and then cudaMemcpyAsync's a new expert into that slot (2088-2091). Any give_back past h issues h+96. The used event that the copy stream waits on is still the previous occupant's event, because the current group's used event is recorded only inside flush(), after the gather kernel (3190-3196). WIDTH
A launch's width is the number of routed experts copied since the previous flush. A flush fires on every streamed hole while a group is open, and the stream sequence is every non-resident, non-peer expert in id order (2028-2068). Width is therefore the run of routed ids with no streamed hole between them. That run is data-dependent. Stage K's 7085 launches over 96 layer-passes is 73.8 launches per pass. A full group of 16 at that expert count would be about 5 launches per pass. The count is consistent with short runs. It is not a recorded width, and the coalesce is unsafe for every run longer than one that crosses a hole. A width counter would not make the lifetime rule safe.
