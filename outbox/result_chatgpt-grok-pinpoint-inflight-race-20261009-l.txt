The broken invariant was host completion of the previous owner group. prev_group_done became 1 when the host function returned, before that group's GPU had retired. Vulkan2 then read that group's device buffers.

A1, ORNITH_TP_DIAG_A1=1, joined the GPU0 D2H worker before Vulkan2 apply/prepare. The first join was 89264 us and the head stayed wrong: length 138, "working on a Stor". Waiting out the GPU0 copy does not fix the divergence, so A2 (a later wait on that same event) was not run. The GPU0 event is not the violated edge.

The patch is in the ready-owner group start. Before a group runs, if the previous group's backend is different, that backend is synchronized.
