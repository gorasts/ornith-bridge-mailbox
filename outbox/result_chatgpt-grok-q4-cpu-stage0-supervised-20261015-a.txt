26s D2H DRAIN CAUSE

The 65th live D2H slot acquire calls ggml_cpu_worker_sync, which force-seals and runs every queued CPU job to completion, including each job's GPU semaphore wait and its matmul. Slot release happens in the worker before the matmul (ggml-cpu.cpp input loop, then graph_compute_sync). A slot stays busy from CAS until that job is dequeued and finishes wait+memcpy+release. One worker thread does that serially. The scheduler can acquire further slots, and submit those copies (submit is before add_input), until 64 are outstanding. The next acquire blocks in the global drain.

The 26.011 s is one backlog drain at the ubatch 17-32 boundary, not one expert matmul. The matching split records graph_ms 0 because the blocked thread is inside the copy, before that split's graph. The worker during the drain is running earlier jobs. Those jobs each do waitSemaphores and then a CPU MUL_MAT_ID.

What fraction of the 26.011 s is CPU matmul versus GPU semaphore wait is UNKNOWN. The slow-split log keeps only 8 lines over 100 ms, so it cannot be summed. This 16k log has no /proc/task utime. Older 8-15% host samples from the 31619 build29 run were 15 s polls and are not this window. A 14-thread AVX2 matmul that filled the wait would show about half of 28 logical CPUs. That sample does not exist here.

D2H staging is per slot. busy is set by CAS and cleared after the GPU wait and the memcpy, before the matmul. The GPU copy is submitted before add_input on the current source. The graph is cloned at enqueue. At the 22.6 s sync the log says range=177, so input ranges were registered. A destination use-after-reuse is not proven.

Deadlock shape: ggml_vk_d2h_wait has no timeout. worker_sync has no timeout. Unpatched pool-miss calls worker_sync, and worker_sync calls park(0) before waiting, which is what submits parked command buffers. The failed patch waited for a slot before submit and before park. A worker blocked in waitSemaphores on an unsubmitted buffer, with the scheduler blocked in that wait, runs until the 2 s fallback.
